# ICLR 2025–2027 Submissions: Topics and AI Safety Labels

All ICLR 2025, 2026 and 2027 submissions (74,498 papers), each with a fine-grained topic label. The 10,381 AI-safety candidate papers from 2026 and 2027 also carry paper-level safety labels. This is the data behind the *ICLR 2027 投稿图谱* dashboard.

ICLR 2025–2027 全部投稿（74,498 篇）及每篇论文的细主题标签；2026–2027 年 10,381 篇 AI Safety 候选论文另有逐篇标注。这是「ICLR 2027 投稿图谱」dashboard 的底层数据。

## Files

```
submissions/iclr{2025,2026,2027}.parquet   one row per submission
topics/clusters.csv                        300 topic clusters with names and per-year counts
safety/labels.csv                          10,381 safety labels (2026, 2027)
safety/TAXONOMY.md                         labelling guide and code definitions
aggregates/*.json                          statistics shown in the dashboard
```

```python
import pandas as pd
papers = pd.read_parquet("submissions/iclr2027.parquet")
safety = pd.read_csv("safety/labels.csv")
core = safety[safety.relevance == 2].merge(papers, on=["year", "id", "title"], how="left")
```

### `submissions/iclr{year}.parquet`

| column | |
|---|---|
| `year`, `id`, `number` | OpenReview forum id and submission number |
| `title`, `abstract`, `tldr`, `keywords`, `primary_area` | as submitted (`tldr` empty when not given) |
| `status` | `accept_oral`, `accept_spotlight`, `accept_poster`, `reject`, `withdrawn`, `desk_rejected`; 2027: `active`, `withdrawn`, `desk_rejected` |
| `rating`, `accepted` | mean reviewer rating and decision; empty for 2027 |
| `openreview_url` | forum link |
| `topic_cluster`, `topic_name_en`, `topic_name_zh`, `theme`, `topic_centrality` | fine-grained topic (0–299), its name, one of 17 broad themes, and how typical the paper is of its cluster (negative distance to the cluster centre; higher is more typical) |
| `style_score`, `formulaic_style` | abstract-wording score and whether it exceeds the 2026 99th percentile (7.18) |

### `topics/clusters.csv`

One row per cluster: English and Chinese names, theme, a one-line description and trend note, `coherence` (3 = one clear topic, 2 = coherent with some mixing, 1 = grouped by shared wording rather than subject; 15 clusters, best excluded from trend claims), counts and share per 10,000 submissions for each year, the same share after removing papers with `formulaic_style`, and 2026 acceptance rate and mean rating.

Themes: `agents`, `llm_post`, `llm_core`, `mm`, `gen`, `vision`, `embodied`, `rl`, `safety`, `interp`, `theory`, `struct`, `science`, `eval`, `repr`, `systems`, `apps`.

### `safety/labels.csv`

| column | |
|---|---|
| `relevance` | 2 = AI safety is the main contribution (6,474), 1 = secondary motivation (2,475), 0 = keyword match only (1,432) |
| `subfield`, `subfield_2` | one of 26 codes (e.g. `JB_ATK`, `PI`, `AGENT_SAFE`, `REWARD_HACK`, `OVERSIGHT`, `UNLEARN`), `NONE` for relevance 0 |
| `contribution_type` | `attack`, `defense`, `eval`, `analysis`, `method`, `theory`, `position` |
| `target_system` | `llm`, `reasoning`, `mllm`, `agent`, `multiagent`, `diffusion`, `rl_robot`, `classic`, `general` |
| `topic` | short free-text description of the specific problem |
| `candidate_by_area`, `candidate_lexicon_hits` | why the paper entered the candidate pool |

Definitions are in `safety/TAXONOMY.md`.

## How it was made

- **Submissions.** 2027 comes from an OpenReview API snapshot taken on 2026-10-07, after the abstract (Sept 18) and full-paper (Sept 25) deadlines. 2025 and 2026 come from the paperlists collection, including rejected and withdrawn papers. We fetched both on 2026-10-11.
- **Topics.** TF-IDF on title, keywords and abstract (1–2 grams, title and keywords weighted ×2), reduced to 300 dimensions with truncated SVD, then k-means with k = 300, fitted jointly on all three years. LLM agents named each cluster from its top terms, top author keywords and sample titles.
- **Safety labels.** The candidate pool is papers whose primary area is safety/alignment/privacy/fairness, plus papers matching a safety keyword lexicon. LLM agents labelled each candidate from its title, keywords and abstract, following `TAXONOMY.md`. A script checked every label against the allowed codes. Labels were not checked by hand paper by paper.
- **Wording style.** A score built from wording markers whose frequency changed sharply in 2027 abstracts while being spread evenly across research areas. 42.4% of 2027 submissions exceed the 2026 99th percentile. The score measures wording only; it says nothing about authorship or quality.

The pipeline is in the parent repository's `scripts/`, and this folder is regenerated by `scripts/export_release.py`.

## Caveats

- The topic and safety labels are model-generated and suitable for aggregate analysis. Check individual labels before citing a specific paper.
- 2027 has no reviews or decisions yet. The 2027 status reflects the snapshot date.
- Compare years by share, not count: 2027 has 2.17× as many submissions as 2026.
