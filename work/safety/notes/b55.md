# b55 observations (173 papers; ~2026 vs 2027 comparison)

- **Agent memory is a new attack surface in 2027.** Several papers target persistent agent state rather than a single context window: EvoForge (ppYFgqyUT4, splits a payload across ordinary interactions so the agent's evolving memory assembles it), MemMorph (FmGV49IXl9, poisoned long-term memories that hijack tool selection), SynChain (BjsV3exEKv, induces computer-use agents to write poisoned skills and artifacts that reactivate later) and CAMEL (i4ahnQl7Vu, spurious correlations in agent memory). The 2026 prompt-injection papers in this batch focus on single-session injection (APaE1JUje1, MASpi 1khmNRuIf9). The one 2026 exception, Deep-Cover (U3kxnDzuRz), runs injections over many turns against Claude Code and Gemini-CLI.
- **Agent-security threat models in 2027 go beyond "follow the injected instruction".** Examples: visual data injection (BvWqxUZfnY), where screenshot pixels supply unauthorized tool arguments without any instruction; attacker resource capture and billable-use inflation (REAP, DjA3vVzq12); kernel and syscall telemetry for agent security (gejhRo8Pdz, 17 threat models mapped to OWASP agentic categories); and optical context compression bypassing refusal (Refraction Gap, f722QmweC5).
- **2027 work measures how reliable evaluations are, not just attack success rates.** Examples: replay non-determinism in harm attribution on AgentDojo (N06sb3govF); whether prompt-injection susceptibility persists across held-out attacker goals (CASPER, MZodbg4BOZ); anytime-valid bounds on unseen failure modes before deployment (UO9oWYp6W8); forced-routing probes showing that MoE unlearning can look complete while the router only hides the knowledge (qTH7I1CkN6); quantized reward models flipping 1–12% of preference decisions while headline accuracy stays the same (u2AWpCOTtb); and an "interpretability lottery" in which automated SAE feature labels are unstable (5m4uz1NzTg).
- **Monitoring and oversight is a clearer 2027 cluster, and it is aimed at agents.** Papers include: reward misspecification degrading CoT monitorability (l0SF216FM3); self-attribution bias, where monitors judge their own earlier actions more leniently (frjth7SlNd); predictive monitoring from partial trajectories (PreAct-Bench, JNQyvp2woZ); weights-only auditing of harmful SFT from checkpoint deltas (TRACE, dj3jCaz82F); and whether models can control their own activations to evade probes (FRbun5b5GA). The 2026 counterparts are mostly CoT-faithfulness and trustworthiness training (ReFIne nCgMpMDgR2, 5d1M87NQDq).
- **Recurring benchmarks and models.** AgentDojo and InjecAgent are the standard prompt-injection testbeds in both years. TOFU and MUSE are used for LLM unlearning. Contextual integrity is now the main frame for agent privacy: AgentCIScope (UkYifKhPOx) and PiSAs (bNQK9SINaM), the latter covering multi-user shared agents. 2027 papers often name new models (Qwen3/Qwen3-VL, Qwen3.6-27B, Gemma 4, FLUX/SD3 flow-matching), while 2026 papers use GPT-4o and Llama-era models.
- **Generative-safety methods follow the move to flow matching.** 2027 concept-erasure and steering papers target flow models: BEM Bregman erasure (xwnYE6MomD), Mosaic compositional multi-concept erasure (ZI9idAGuoL), HypSteer hyperbolic steering (EBMCrq3rwK) and PaLo-Steer (fUVcAp2Wqx). There are also new benchmarks such as LU-500 for logo unlearning (z8QUyYrB1e) and semantic underspecification as a non-adversarial T2I risk (s5GIYSs8JN). Watermarking work in 2027 covers forgery attacks (EraseForge, l2m0rp84rU), audio watermarking (CHORD, ZAGo19Qlq4) and detecting mixed human/AI authorship at fine granularity (OpAI-Bench dmXYZPyw2C, AI-involved code 84DTHAm97R).
- **Poisoning without triggers or with unusual triggers.** Examples: misinformation that changes downstream decisions without any trigger (p822NKLWR3); document heading hierarchy used as a backdoor channel (iC8Bmj9kiY); and implants that activate only under a particular batch order (zVkL0dx6xz). In 2026 the backdoor papers in this batch are more conventional (concept-triggered VLM backdoors O2d44Oe0im, RL backdoors YM23GVqQqj).
- **Other new 2027 harm framings.** LLM paternalism in personalization (zRvZBHHDpe), source-preference bias in shopping and search agents (uSJnMmyk9o), emergent pathologies in LLM agent societies such as Moltbook (xPEvuCGFZF), and preference stealing from Best-of-N serving (RnsavZx5z7).
