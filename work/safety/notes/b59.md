# b59 qualitative notes (173 papers, 2026 vs 2027)

- **Agent threat models move from single prompts to persistent state and the tool supply chain (2027).** AutoRedClaw (OWlbp6QYsD) red-teams "claw-style" persistent assistants (OpenClaw, AGENTS.md, long-term memory, skills), where a poisoned config is reloaded in every session. MalSpot (bIQZX73AJm) statically finds malicious code in agent tools. A2E/MCP-COMPOSE (nc9nNZvFZZ) evaluates MCP agents by checking action, policy and effect evidence. Purpose IR (XwjF5Ue6MF) compiles user purpose into a privacy boundary for agent memory. The 2026 agent work in this batch is still about red-teaming code agents (RedCodeAgent, IyIaAOihmZ).
- **Red-teaming becomes standardised and automated (2027).** SuperRed (h7jjGRtosD) makes attacker access, feedback, model and budget explicit. It shows that ASR moves from 2.7% to 67% depending on the threat model alone, and it red-teams Claude Code as a target (about $130k of inference). DART (UCqXhDA4Mw) uses LLM agents to build adaptive attacks against 51 adversarial-example defenses from AutoAdvExBench. In 2026, automation means agent-driven backdoor injection (AutoBackdoor, J2UFyF9YeD).
- **Mechanistic and representation tools now target concealment and evaluation integrity.** Examples: a Concealed-Information-Test probe that separates sandbagging/concealment from real unlearning (r4Mqry4w5v, 2027); steering that suppresses evaluation awareness (1TdRdf0fkw, 2026); a weight-editing "decoy direction" defense against abliteration of open weights (0qsTfF8zdK, 2027). There are also more sceptical 2027 interpretability papers: attribution graphs fail to predict jailbreaks (eBNIxFoFcD), circuits miss model errors (XAvswNGHmG), and decodability is not capability (wteTfM1uZR).
- **New 2027 safety dimensions beyond content harm.** Physical vs content danger in embodied LLM hidden states (kd55TEsmFk). Vision-induced safety degradation in MLLMs (X9GxuB55r5, BSJKBwDhXJ "cross-modal safety desynchronization", sWgZPtNbGa refusal subspace with 272 parameters). Multi-turn "when to intervene" supervision (mg8ETguyGt). "Model hypnosis" from additive subliminal cues (9mLXHDASyb). Resource-exhaustion/DoS prompts against reasoning models (DTqbYEq3FB). Tutor-integrity attacks in education (idEOpdnzBk).
- **Provenance and detection stay large and get more careful about evaluation.** In 2027 the detection papers add audits for leakage and temporal shift: "Trust, but Verify" on 2026 frontier text (zk9xpLKpBl), conformal risk-controlled localization of mixed authorship (F5jQvWBvu6), and MLLM-reasoning AIGC detectors (RafiZ0ikvb). Agent-evolved image forensics also appears (ForenEvolve, V8AVsJ445k). The 2027 paper 2pEA9r9V3E uses Pangram to estimate that about 27–31% of filtered 2026 web tokens are AI-generated. Audio deepfake detection on speech SSL front-ends is a recurring sub-theme (z68XxlkxC3, HFfcBg8MZo).
- **Privacy work shifts toward post-hoc and deployment-time fixes.** RAISE edits a checkpoint after fine-tuning to mitigate MIAs (U8CMAlFIxo). Other examples: debiased post-hoc privacy auditing of foundation models (wxEvaxbxFl), TEE-GPU obfuscated inference attacked and defended (RlW0Jx9mSG; TwinShield nCJF1CDapQ, 2026), PII unlearning in VLMs (eOWuCBz4aE) and disclosure control for embodied VLN (OwEK7LcLIL). Harmful-fine-tuning defense now uses adversarial training against simulated full-parameter attacks (Patcher, 0UKlWE7EKV).
- **Recurring artefacts.** Benchmarks: MM-SafetyBench, HoliSafe, MOSSBench, WMDP, BookMIA, TruthfulQA, RewardBench 2, LLMBar, AutoAdvExBench, LIBERO. Models: Llama-3.1-8B, Qwen3-8B, Gemma-3, Qwen2.5-VL, and Claude Opus / Claude Code as targets or attackers. Many 2027 abstracts are heavily controlled measurement studies (matched nulls, permutation floors, leakage audits) rather than new-SOTA method papers.
