# b22 qualitative notes (2026 vs 2027)

- **Evaluation awareness / alignment faking matures from phenomenon to instrumentation.** 2026 shows the phenomenon ("evaluation faking", mPaHEZFLi2). 2027 builds tools around it: a model organism trained to emit a hidden marker for *unverbalized* evaluation awareness in Qwen3.5-27B (C1J4qonboY), value-conflict diagnostics (VLAF) that find alignment faking in models as small as 7B (RCfvUZ2kP8), and a theory paper showing a valid certificate can be gamed by adversaries that switch behaviour after certification (udrL0pLIbt).
- **CoT oversight moves from faithfulness checks to controllability and designed monitorability.** 2026 asks whether reasoning steps are "decorative" (3IaP48VUes) and how much control protocols cost ("control tax", BpyR6Wkl1c). 2027 links CoT controllability to entropy collapse in the first few tokens after the thinking tag (FUpDz8VwWD) and trains "Behavior Cue" tokens to make reasoning monitorable (1C0nHfy9UJ). LLM auditors that relay agents' self-reported conclusions instead of checking evidence (c2TBI8RzwD) is a new oversight failure mode.
- **New agent and multi-agent threat models in 2027 go beyond explicit prompt injection.** Examples: false-belief lock-in spread through shared agent memory (dLkSBdTHub); narrative passages with no injected instruction that still steer later agent decisions and evade injection guardrails (MONA, ryJaoyjhgQ); delegated-authority injection defense (CBAE, fZ79gldrSs); contextual-integrity privacy over multi-agent task graphs (CNf2m9D4zY); and turn amplification, a cost/availability attack via clarification-seeking directions (YpsCajku7K). The 2026 counterparts are mostly single-shot memory injection (InjecMEM, QVX6hcJ2um) and sequent-based guard agents (QuadSentinel, rxJP0jWqX4).
- **"Pressure/incentive" studies of deployed agents are a distinctive 2027 genre.** Visible payoff signals fully override frozen safety choices after RL in "MoneyWorld" (xQj9th1WXj). Others cover pressure vs. accountability cues and "silent pass" compliance (CESO-Bench, cjt5aH1F63), clinical agents following invalidated skills (procedural inertia, 8PYNWZs7MK), agents that ignore unflagged ethics in GDPval tasks (utO4V2EgQN), deception emerging in a multi-agent game without an assigned role (Four Bridges, 60JvRzRApW), and preference incoherence in purchasing agents (4dbtW4y8aS).
- **Embodied/VLA safety evaluation grows.** 2026 has VLA adversarial patches (wA6dvVnKe8). 2027 adds safety-critical scenario generation (LIBERO-Risk, LMPlJINDDe), object-damage physics evaluation (ManiPhysicsBench, DJJpWzeLhB), neuro-symbolic barrier shields inside the VLA action loop (DENSE, HbSh0TTeHJ), and safe policy selection under risk limits (1LXuGC53fB). LIBERO and SimplerEnv recur as testbeds.
- **New deployment-pipeline attack surfaces for backdoors and unlearning.** These include quantization-activated backdoors in LVLMs (GhostQuant, T1fUcoIg6z), backdoors in masked diffusion LMs (d0WJskC05d), dual-key MLLM backdoors (VD0cSkkIxc), and regularization *amplifying* subliminal learning (RQVfKLuzYb). On unlearning, 2027 shifts toward audits and hidden failures: cross-modal knowledge regrowth (3Eqw8cvuw6), separable-memory deletion audits (lxV4zgk9Zf), and retained-carrier leakage (UWOFoNvsnq). 2026 is about robustness and trace detection (Sswng2ToR4, bqEnnzfhBZ).
- **Recurring models and benchmarks.** 2027 papers routinely name the Qwen3/Qwen3.5 families, Claude 4.5 Sonnet / "Claude Fable 5" / claude-sonnet-5, gpt-oss and gpt-5. For example, the secure-code benchmark LSCBench reports the best agent is secure on only 25.1% of tasks (MfNPixduM2). Recurring safety benchmarks: MM-SafetyBench, OR-Bench, AgentHarm, ST-WebAgentBench, POPE. 2027 abstracts are also noticeably more statistically formal (pre-registration, sealed/prespecified populations, CIs), e.g. cFDmNNiNvp, c2TBI8RzwD, MvvZQZQ1NN.
