# b58 qualitative notes (2026 vs 2027)

- **2027 agent security focuses on supply chain, memory and authorization, not only prompts.**
  - Clawdrain: a trojanized OpenClaw skill that causes 2–16x token resource exhaustion on Gemini 2.5 Pro, DeepSeek V4 Flash and Claude Sonnet 4.6 (9xiMjRLKDP).
  - ProbeID: behavioural probes that verify MCP tool identity against squatting and rug pulls (FuarZrC0Ob).
  - Agent memory as an attack surface: memory misevolution, controlled with RAMA on MemEvoBench (5uiWbG4P81); verification-gated memory writes that hold up under forged-entry injection (cLLimEnHqU); and recorded lineage of external records inside agent state (EUiwYKQQVt).
  - Authorization-scope policies learned from counterfactual request pairs (td6jCPkD5k).
  - Stale tool-call authorization in full-duplex voice agents (6HB5ngatyS).
  - In 2026, the closest work is control-flow hijacking in multi-agent systems, with the ControlValve CFI defense (PNU9Rj5RDQ).
- **New 2027 multi-agent and self-improvement threat models:**
  - Distributed backdoors split across agent messages, with a total-variation bound on how well single-fragment monitors can do (GNWMrNlBlX).
  - Unsafe programs that persist across recursive self-improvement generations (ELoktlfkCU).
  - Retrieval-stage "value steering" in agentic search (zcr9Q9HTWQ, RIVET).
  - AI-injected visual misinformation against multimodal search agents (7mxxQAMSIU, M³Search; Gemini-3.1-Pro reaches only 45.6%).
  - Agent-driven auditing of reward hacking across 567 environments, with 17 attacks reproduced on the SWE-bench Verified harness (VXFTF9Je8S, RewardProof).
- **Misalignment model organisms and monitor evasion.**
  - 2026: Neural Chameleons, where models learn to evade unseen activation monitors (eSI3t4fAG8).
  - 2027 moves toward data-driven origins of misalignment:
    - Synthetic documents about AI users shift trust and cooperation in Qwen3-32B (sZbc4jhm0S, "social priors").
    - Aligned data can cause narrow misalignment through "context confusion" (eiZIgH3WFy).
    - Canary-controlled data interleaving mitigates emergent misalignment (cYCQVr0BgI).
    - The safety risk of fine-tuning data depends on the model's state, not on the sample alone (Jo6U0y2omr).
- **Refusal and jailbreak work in 2027 increasingly works in representation space.**
  - Defense against multi-direction refusal-subspace ablation on open-weight models (jDhBl5eznH, ReSAT).
  - Local null-space refusal steering (WjjXW0nQ2T, K-Shield).
  - Video LLMs refuse less as more frames are added (y01WnZj2L0, R2R).
  - Narrative wrappers move harmful requests away from the refusal direction (2iMLiUrBiW, GUISE).
  - CoT Hijacking: long benign reasoning dilutes the safety signal, with ~94–100% ASR on frontier reasoning models including Claude 4 Sonnet (OSgCinkK4B).
  - In 2026 the jailbreak work in this batch is mostly prompt-level search: RL rewards (LSZ0adCum7), dialectic games (ilnKzaQSCh) and UMM multi-turn attacks (rM8lcZxbj9).
- **Mobile, video and embodied surfaces in 2027.**
  - MobileJailBench: an evolving jailbreak benchmark for mobile agents across 20+ apps (42objvKs3y).
  - StreamGuard: a real-time streaming video guardrail (lmSBVhSU4E).
  - TrajPoison: clean-label poisoning of VLA demonstrations (uAv7O4goMB).
  - GeoPhase: a control-barrier-function safety filter for VLAs (wTqtwsJEky).
  - Reasoning-action faithfulness of the Alpamayo-R1 driving VLA, where fewer than 40% of scenes have fully faithful reasoning (5bhvNK0YbL).
- **Privacy and IP in 2027 target new leakage channels.**
  - Membership inference from MoE router telemetry (nzMingpyzV); this also appeared in b48.
  - Trace Inversion: stealing reasoning ability without access to reasoning traces (t8p3BkzOKo).
  - Zero-shot LLM private-attribute inference on tables (vzRprHSvdU).
  - Detectability of identity-unlearning requests (uxNbEubRfu).
  - In 2026, related work covers SMOTE reconstruction attacks (ZQSZMpsQKj) and copyright memorization tests (QJku1vSXrJ).
- **Method style in 2027: more audits and more self-critical measurement.**
  - Interpretability and SAEs: symmetry and identifiability tests for SAEs (bJI3LHVQRT, wk6OkmtqRS), and a result that activation interventions can fail to identify component rankings (eVH5WVDHZD).
  - Robustness and backdoor evaluation: a pre-registered invariance audit of OOD detectors (mAG2nMgPOg), and a BackdoorBench scheduler artifact that inflates defense "costs" (FKMA2UD8GS, TARE).
  - Unlearning: compositional-query evaluation of unlearning on TOFU, WMDP and MUSE (hu43nQaERO, RAQUEL).
  - Recurring in 2027: Qwen3 models, ICLR peer-review data (SZEO5MrQN5, which finds LLM reviewers favour LLM-written papers), and many detectors of AI-generated images or fraud (TbdXqLjruE, WtGCxYPpvD, UB6efsd4Jp).
