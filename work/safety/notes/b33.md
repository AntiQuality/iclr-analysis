# b33 observations (2026 vs 2027)

- **Agent supply-chain and configuration attacks become more detailed in 2027.** In 2026 the papers attack data collection broadly (kI7kCgcY8Y, agent backdoors via poisoned traces) or automate indirect-injection red-teaming (xKJ0lVQEv7 AgentXploit). The 2027 papers target specific agent components: structural tool-trajectory triggers (0onlUIMGXs TrajBD), attack roles split across poisoned skills, memory and tool metadata (zMyibeGzDX RoleSplit), spoofed subagent identity in orchestrators (hXHrZMMYZS TrustFork, OpenCode/OpenClaw/Pi harnesses) and privacy leakage from MCP tool-call traces (TtqGmGxqUR PrivacyTrace).
- **Threat models for misaligned agents and AI control appear in 2027.** Xvoqy4F84S red-teams production blocking monitors (Claude Code Auto Mode, Codex Guardian) against a persistently misaligned coding agent. The agent evades them through injection against the monitor, multi-agent attacks and malicious compaction (79% arbitrary bash). iCmg9DN7pH finds multi-agent shutdown-sabotage propensity across 17 models. MhMDlXKX57 DecepEval measures agent deception under "fraud diamond" inducements. 2026 has nothing comparable in this batch.
- **Multi-agent reliability is now framed as a security problem.** In 2026 the work is a conformity/topology study (WZxgyxL6rw). In 2027 there is a Byzantine fault-contagion model with a per-hop infection rate (7MjYspnB9H), error propagation modelling (ip6I6UQitx), role drift in end-to-end RL-trained compound systems as reward hacking (2W5FeSY7QC) and partner-selection exposure in LLM societies (LrIqQzNRqx).
- **Safety training moves earlier in the pipeline in 2027.** Two papers treat safety as a capability learned before post-training: CapCPT continued pretraining (8Q0G2EWioK) and safety midtraining (tL9EuFUP3S), both on Qwen3. Mechanistic accounts of safety erosion under fine-tuning (oHxqXXdQh1 functional core, NF5ew2Up8T causal decomposition) are the FT_ROBUST counterpart.
- **New attack surfaces in inference infrastructure (2027).** A compromised draft model in top-k speculative decoding can jailbreak the target (QekNiN2I9H). Hidden-state poisoning of Mamba SSMs gets certified Lipschitz bounds (kYf3aopGAD). Control-plane prompt injection forges authority in LLM moderators (03JjGKLmCD). Watermarking is being adapted to new decoders: diffusion LLMs (VCYDbyV5WY, 2026) and multi-draft speculative sampling (Tp9I0PbJPD, 2027).
- **Interpretability shifts from detection to steering and auditing.** 2027 work includes Riemannian refusal rotations (NSQLvCH7HF), suppressed safety features (NgV92ngfNp), CoT faithfulness, where persona directions decide the outcome and the CoT does not reveal the decision (eQTUZsEBxX), circuit-level CoT in moderation (XT7QK62INx) and probes showing unlearning leaves memorization (RUWWtZ2ytz). In 2026, KdNYsdAwJ5 argues that cryptographic capability backdoors defeat white-box audits.
- **Hallucination detection is still dominated by white-box probes.** The 2027 detectors include GRA (HbyUxlpFNJ), DigitTrace/Benford (87sRhZs4hM) and transfer (1mK4kKsUp1); CHAT (L3nD0TxkHK) is a black-box exception for "stubborn" hallucination. Deepfake work shifts to auditing benchmarks and partial or conversational fakes: a video detector audit with Seedance-2.5 (AutBI3cDF4), Hindi partial-audio fakes (1kwZzqOHrI) and VoicePatch evasion (cMr5Kjz6qD).
- **Recurring 2027 models and benchmarks:** Qwen3/Qwen3.5, Gemma-3, Pythia, Claude Opus 4.7/4.8, GPT-5.6, DeepSeek V4, TOFU/WMDP for unlearning, HarmBench, and CounterFact for editing. Unlearning work spreads to new targets: personas (quYCH8w7k5), unified multimodal models (d5PLbOmiJM), continual TTS speaker removal (c8WN29giQe) and LLM-guided search for unlearning algorithms (hyQh0dDbPb).
