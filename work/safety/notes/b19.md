# b19 qualitative notes (2026 vs 2027)

- **The agent threat surface moved from the prompt to the system plumbing in 2027.** Several 2027 papers attack or audit the pieces around the model rather than the model itself:
  - injected content that re-enters through planner/executor state handoffs (3caudXTDvX, "trusted-state laundering")
  - ordinary SMS notification text that hijacks mobile-use agents (3ZMZfr8Cpi, PhoneJacking)
  - one fact copied across many web pages so it looks independently confirmed to multi-agent search (zTIsl6PtIl, SourceSplit)
  - stealing the "harness", the scaffolding that runs a multi-agent system, as IP (6kjTlyCrof)
  - authorization of long-term agent memory (Q10oKchkHw)
  - In 2026 the agent papers were mostly benchmarks: SafeAgentBench (BFb4ACHayj), MIRAGE-Bench (jau7d0SfPQ), SPILLage oversharing (clyjBLBnKE), PropensityBench (jOTQupHx7q).
- **Byzantine, federated and self-modifying agents appear as new multi-agent risk framings in 2027.** Examples:
  - A2A-BFT, Byzantine fault-tolerant consensus for agent-to-agent protocols (UCVkNnEWbN)
  - "false safety consensus" among federated agents (SxXatJRBnu)
  - a position paper arguing that safety analysis of self-improving agents needs causal inference (KIdmC9bg7Z)
  - The 2026 precursor is Alignment Tipping (B4ICxIxrvH), which shows self-evolving agents drifting away from their alignment.
- **Agent policy compliance is now an object of study.** Three 2027 papers (UG830hrcwF, GICPSMuCNI, SeKOGWQSYq) ask whether agents follow organisational policies or procedure manuals. They test Claude/Qwen agents and use runtime "shields" to enforce compliance. 2027 papers also name newer frontier models: Opus 5, GPT-6 Astra and GPT-Image-2 appear in ptdxxQtsyV and nVGeJRTQr6.
- **Interpretability-for-safety now targets agents and reasoning models, not only chat refusal.** Examples:
  - 2027: steering an agent's internal "thoughts" before it calls a tool (mqTpEF5tY7)
  - 2027: tool-mediated requests need a higher harmfulness level before the model refuses (ZYSU20zoD5)
  - 2027: jailbreak format shapes activations more than harmful topic does (FWWxurgGqo)
  - 2027: vision inputs suppress safety neurons in VLMs (8NbAF0cIQs)
  - 2026 counterpart: the "refusal cliff" in reasoning models (ikmBOPAozE)
- **Frontier-risk and character work in 2027:**
  - VeriEnv turns written frontier-risk narratives (scheming, sabotage, peer preservation) into executable testbeds (gRa5wtmWDF)
  - character/constitution training to make agents risk-averse (dYPpkd7aHu)
  - honesty training evaluated on MASK, Among Us and AuditBench (5kXox7ovrd)
  - backdoors that fire only when the context offers an opportunity, hiding behind plausible "alibi" reasoning and fooling LLM inspectors (3yj7dmpfuT)
  - LLM-run Delphi panels for AI-cyber risk estimation (0QZXJDSwuc)
- **Watermarking and provenance are a large 2027 cluster with new channels:**
  - autoresearch agents that discover new watermark schemes (ptdxxQtsyV)
  - watermarking carried through LLM-judge reward scores (7NBlFCtd2e, Radioactive Feedback)
  - black-box watermark auditing by changing top-k (iKMIxY00jB)
  - regenerating images with an API model to remove watermarks (nVGeJRTQr6)
  - keyed and codec-robust audio watermarks (6sUkV5xfsS, 3RYsgXS0uj)
  - word-level detection of AI editing (NWmbeQDCvc)
  - Related privacy finding: a released LoRA adapter identifies the exact document it was trained on (u82w02YBmy).
- **Unlearning and fine-tuning durability:**
  - 2027 shifts toward pre-release "preemptive unlearning" (gradient sealing, bdZAOqTSho)
  - backdoors that return after downstream fine-tuning (backdoor rebound, idSXehqEgi)
  - safety concentrated in a small fraction of LoRA coordinates (O8dieLuYNC)
  - agent safety after quantization plus fine-tuning, scored with AgentHarm (Ztx6GtIeKG)
  - federated, forward-forward and theory-of-unlearning papers (ddTY9xjAY8, kWMXdNzvA9, pr9gnbb2bs, 4eBhaKJLoE)
  - 2026 work on these topics is more classic: corrupted-data unlearning, editing-based backdoor injection, and the prefilling/top-token shallow-alignment critique (GpBo97z6GH).
- **Hallucination detection remains a high-volume, incremental area in both years.** It is mostly single-pass white-box or logprob probes (TLRoCrm0U8, 2vvu4s8uw4, cWWd9pZpe0, Z4wVtY7PrV) and MLLM mitigation (LIFE iAurTEUrky, PA-OPSD mz9B4eruYp, TARS cHILNck9eW). There are few conceptual changes. One newer 2027 framing treats it as cross-source evidence grounding for search agents (bNKV0YT7Nc).
