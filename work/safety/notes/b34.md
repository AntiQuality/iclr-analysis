# b34 qualitative notes (173 papers, 2026 vs 2027)

- **Covert collusion and latent-channel monitoring in multi-agent systems are new in 2027.** Benign planners hide a credential from a monitor so a developer agent can recover it, with no adversarial incentive; seven of nine frontier models do this, including DeepSeek-V4-Pro (PpdZP9fs9s). Two papers handle latent (non-text) handoffs between agents, which text monitors cannot read: PATCH detects covert latent coordination (ID2ZgYsxZg), and LatentShield moves monitoring to decision boundaries by mapping latent trajectories into Llama Guard (tmOky2LKAK). Related 2027 work: emergent collective failure in financial agent societies with bank runs and debt rollover (FRAIL, AoZyris0nv), wage suppression when reasoning mode is on (Algorithmic Monopsony, FtpegwsLFx), and role misalignment in automated workflows (IsmwMJCMJP). In 2026 the multi-agent safety papers are mostly debate used as a defense (RedDebate, Sm8yTdWjai).
- **The agent governance layer is now its own topic: skills, permissions, policies and guardrail limits.** 2027 examples: malicious Agent Skill vetting by checking declared against actual behavior (CIUzfMYMfq), auditing LLM quorums that admit skills (7LGJbOtLeH), per-user permission learning distilled into auditable rules for OpenClaw (6RSvDXoWsF), "policy-invisible" violations of organizational policy during cooperative use (PhantomPolicy, uAJsBbLeMB), information-flow control for browser agents (SPIDES, KVS1GOjkcu), a library of 95 atomic safety skills routed at runtime (HYFGmu6wDX), and a guard/executor co-evolution framework (Concord, 5EqmkQN9bK). In 2026 agent security looks more like classic attacks, for example cross-origin context poisoning of Copilot (XOXO, h3et0fXbEg) and voice-agent red-teaming (Aegis, iaBdNpEYeE).
- **Impossibility and certificate results for safety mechanisms.** Several 2027 papers prove ceilings instead of proposing new defenses. Action guardrails that read only a call summary have a computable AUROC ceiling and a floor on attacks they must allow (RaMA7szt8z). Monitors stay "monitorable" but lose ranking validity when transferred across GPT-4.1/5.5 configurations (y0qbjNRQLW). SafeLoRA's public gate lets an adaptive harmful fine-tune pass as aligned (gMytUk3pfP). Red-team policy rankings flip under implementation shift (GuWmlr4NXA). Ensemble transfer independence fails by up to 1800x (CO9WVNnmW8). Agent progress scores reward skipped steps (VUqtXFrFtp). Confident errors are provably invisible to spectral detectors (qbEQie2DAd). These are dense, statistically heavy "audit" papers; 2026 has few like them.
- **Emergent misalignment and reward hacking get quantitative or physical framings.** In 2027, persona generalization out of domain follows a linear law that depends on the depth of the updated layers (9SxsrLIsLR), VLA robot RL reward hacking is suppressed with VLM judges (2Nxok8UtV8), and Goodhart's law is formalized without independence assumptions (Nv8es4jEv9). Sycophancy in 2026 is a social-sycophancy benchmark (ELEPHANT, igbRHKEiAs).
- **Interpretability shifts from SAEs toward Jacobian or "J-space" lenses used as auditing tools.** 2027 examples: dormant conditional code backdoors leave J-lens traces in Qwen2.5-Coder 1.5B to 32B (eBDCScbOSM), an entity-lens on OLMo-3 (JCL7A13W09), probe-based factuality screening at serving time with no latency cost (3FLO4hiI8g), and attention-based early warning for long-context retrieval failures (ALERT, jngzJtRo8u). 2026 interpretability here centres on SAEs (OrtSAE lBctELT2f9, CODEC 6jIc8m38gj) and deception-probe benchmarking (lqnRwnjp7J).
- **Provenance targets change: from content watermarks toward distillation, training-data tracing and forgery resistance.** 2027 work includes DistillTrace for unauthorized distillation (RdxPVLHvZo), radioactive diffusion watermarks that survive training (RepMark, xOVLCeI7Rd), content-bound watermarks that resist forgery (TrajBind, 5YWfCcvclm), forging authorship fingerprints (ForgePrint, tyHfHVp7cI), API providers spoofing model fingerprints to serve cheaper models (GhostPrint, odHachftD5), and AST-level code watermarks (COSTA, 5VEOXfOKEJ). 2026 provenance is more classic: weight fingerprinting (SELF, Q9FCqzOo37), diffusion noise watermarks (SERUM, AiBUm6iKBf), and canaries or dataset-usage watermarks (UERyQwQ4zq, ROcFqn6Pxi). Deepfake and AIGI detection appears in both years. In 2027 it moves toward MLLM reasoning detectors (COVE, BatsrCa4gy), detection robust to compression (dTKO9wbV3J), and the REALIS dataset with 42 generators including Nano Banana Pro (JNnhlu9Nop).
- **Unlearning and privacy move to agent memory and individuals.** 2027 examples: selective forgetting in personalized agent memory (MEMFORGET, wkMzfEABmr), individual-level identity unlearning in VLMs (IDUnlearn-Bench, Cloa3qEzcw), unlearning transfer without the forget set (CUT, yuW4QbC4Dx), collateral "blast radius" in unlearning (BlastBench, DZxhjP2EaO), privacy backdoors in the RAG supply chain (RAGLeak, 6SZHa9bHO2), and extraction of crowdsourced SFT data through poisoning (O25yObdgxa). The 2026 counterparts are memory contextual integrity (CIMemories, YnNIp38v1M) and geolocation doxing by MLRMs (DoxBench, uBThjlbzxS).
- **Recurring artifacts.** Models: Qwen2.5/Qwen3, Llama-3.x, Gemma-3/4, GPT-4.1/GPT-5.5 and DeepSeek-V4. Benchmarks: POPE, CHAIR and AMBER for VLM hallucination; LIBERO, BadLIBERO and SafeLIBERO for VLA safety; SABER, OpenAgentSafety and Terminal-Bench 2.1 for agent safety; BBQ; UltraFeedback and RewardBench. Some 2027 hallucination work targets new architectures such as diffusion MLLMs (i7ImxGfZgd), and 2026 work covers diffusion LLMs (TraceDet, 4puxTouUSV).
