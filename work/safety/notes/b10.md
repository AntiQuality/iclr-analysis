# b10 qualitative notes (2026 vs 2027)

- **Agent oversight moves to monitors and verifiers in 2027.** Several papers train or verify monitors for agent trajectories instead of only hardening the model. Examples: Ts9bZceJ5W trains agent monitors on minimal counterfactual benign/malicious pairs and evaluates on CUA-SHADE-Arena. YMaKnJiBg4 uses a latent GUI world model to flag hijacked screen transitions. 93khAI4hyF (TwinCheck) gates memory and skill updates in self-evolving agents. x9FjsKmsNC gives anytime-valid fault monitoring for multi-agent trajectories. In the 2026 papers here, agent security is mostly prompt-injection datasets and challenges (GM9H3iM7VJ, LLMail-Inject).
- **New 2027 threat models:**
  - Persistent agent memory as an attack and failure surface: memory-induced sycophancy (fQYv6LcbdN), harmful propagation through cross-agent semantic caches (b4ocREPHrG) and self-evolving agent state (93khAI4hyF).
  - Population-level red-teaming of LLM-agent societies (vTSgcHXiJJ, CAST).
  - Inference-cost amplification through noncanonical tokenization (pTLQtHJRIW).
  - Leakage through "revision traces", where a model removes an item and then restates it (qf89y8vogU).
  - Agentic re-identification with web search (Qvp2csnCfC, which is labelled 2026).
  - Split-intent cross-modal jailbreaks of image-editing models (slH0HSbKjn).
  - Visual misinformation from commercial image generators (HEB5PBo76C, which reports results on GPT-Image-2).
- **Reward hacking is reframed as specification gaming in coding agents and multi-reward RL.** SpecGuard (AGv9NlfQVp) uses Lean autoformalization to certify task/test conflicts on SWE-bench before the agent cheats. Multi-reward hacking under GRPO aggregation (xSyhsAIPkU), learned best-of-N selection (QYFZ5y8NyK) and attenuating verifiers in multimodal RL (EHHVnaxRKs) are all 2027. Sycophancy is traced to training stages: base-model deference versus post-training capitulation (lHCbJoYyFL).
- **CoT faithfulness goes from measurement to training.** In 2026 it is benchmarked (lN3yKqqzF1 FaithCoT-Bench) or formalized (0qgcZvtQx0, Curry-Howard). In 2027 it is optimized directly: probe-filtered GRPO against "reasoning theater" (MEbLLqrHLy). Safety for reasoning models moves to the process level: risk-aware MCTS (FzmJlwkdlJ) and multilingual thought-response safety alignment (8QqrK0wUU6).
- **Methods get more rigorous: certificates, controls and explicit sanity checks.** Many 2027 papers stress null controls and formal guarantees. Examples: certified copyright budgets (f2jxgNjub6), steering audits with norm-matched random directions (qUXzlLmWS2), sanity checks for hallucination detectors on reasoning traces (3ygyQdzZXH), and adaptive generative prompt-injection benchmarks that show static AgentDojo overstates robustness (RFOUMuMb6L, AutoDojo). Mechanistic-interpretability papers also add frozen versus re-fit probes and matched-budget nulls (YOE8ftDahC, yA2h0UDEIi).
- **MoE internals become a safety and privacy lever.** Router signals are used for hallucination detection (gdGcFLUCnV), per-input safety alignment (7Idfb1oBwM, PIRA) and membership inference from router updates (RF09v6kO2v). All three are 2027.
- **Recurring models and benchmarks.** The 2027 abstracts cite Qwen3/Qwen3.5 (including Qwen3.5-35B-A3B and Qwen3-VL-30B-A3B), Gemma-4, GPT-5.1, GPT-5.5, GPT-Image-2 and Llama-4. Recurring benchmarks are HarmBench, StrongReject, XSTest, AgentDojo, SWE-bench, RWKU (unlearning) and POPE (LVLM hallucination). The 2026 papers more often cite GPT-4o, GPT-4.1, Claude Sonnet 4 and Llama-3.
- **Stable background areas.** Deepfake and AI-generated image/text detection (several per year), LVLM hallucination decoding fixes, LLM unlearning, and DP/federated privacy theory appear steadily in both years. The 2027 papers in these areas lean toward hard settings: pretraining-stage unlearning (XLXTYlzcFF), corpus-free MLLM unlearning (2PakhuDWpn) and detection robust to real propagation degradations (ARbeXboTVC).
