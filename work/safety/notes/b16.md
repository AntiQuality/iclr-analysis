# b16 observations (173 papers)

- Local / personal computer-use agents are a new 2027 threat surface. eWWm1KDHBz DualView finds *stored* indirect prompt injection in OpenClaw-style local agents: a payload is saved to a file and reread as trusted, and the paper responds by tracking untrusted data through the file system. In ZVm5YqO1RH AXIS, GUI agents act whenever the screen offers an action, even if the request never authorized it. gHn31Qj5Wg checks LLM email assistants inside 21 real mail clients and 6 AI browser extensions; only 24% of delegated tasks end in a warning. buhynGpe8l BrowseSafe++ (38k in-the-wild injections, compact 0.8B guard). The 2026 side has benchmark-only VPI-Bench (UMauKu2azg).
- 2027 work moves agent threats into the training pipeline. brOoEhDP1L shows that poisoning 0.1% of the pretraining data backdoors a CLI agent so it runs attacker commands, with ASR around 92% at 4B and growing with scale. 7ijuAIJzLj covers trajectory-level unlearning of agent behaviours, and hl8kmkVpoo shows LLM teams can recover forgotten knowledge through intermediate messages. f3k5bkcD5o TIDES adds a backdoor triggered only by long test-time-scaling reasoning. For 2026 contrast: hSLopCTOtT clean-label CoT poisoning and aS1mI0lqWS code-style triggers.
- Inference-stack and supply-chain integrity attacks are new in 2027. McGNyPiTO0 BadDrafter uses a malicious draft model in lossy speculative decoding. C6corWGbYW RMF fingerprints models at runtime to catch API model substitution across 23 frontier LLMs. YIKFIPyb8M builds zero-knowledge proofs of model binding plus private tool-call authorization. oJWlezUBd8 CIRA studies failures caused by visual-token compression. These build on 2026 CoIn (Epd2N9b76r), which audits hidden reasoning-token billing.
- Measurement-validity and meta-evaluation papers dominate the 2027 analysis work. fuHj7Wb9zd uses AgentHarm benign twins to separate "unwilling" from "unable" refusals with a pre-registered estimator. AV5se53oxk finds that activation-steering gains come with degraded outputs. wusNjuEb6G finds that likelihood-based stance audits match generated answers only 27% of the time. olbdGYAplT shows a text-only classifier beats every VLM on a radiology hallucination benchmark (leakage). oYMqnOdLFI shows HealthBench rubrics miss injected hallucinations. cKVXkbGqgs VeriBench-Wild finds judge pipelines accept the same outputs at 15–63%. 3KUTq95sXr and 2026 hrcpeLrtqE (hidden-intention detection collapses at low prevalence) fit the same pattern. Pre-registration language recurs in 2027 abstracts (fuHj7Wb9zd, oTy3pIHiUt, QynbfSHHfr).
- Alignment, deception and auditing: 8XSsUjMzmg (Synthetic Persona Pretraining) moves alignment into pretraining from token zero using a value constitution. lyzloSZBGx models agent deception as a partially observable game between agent, monitor and verifier. N64uljl5dT compares six frontier models under steering: GPT-5 withholds its reasoning while still answering, and Claude Opus 4.7 resists suppression. 4zVr06zr8K releases 1,036 alignment concept vectors built from 2M synthetic stories. On the 2026 side, nrinbZTy26 (secret elicitation; prefill attacks work best), R1SxYK1LCs AgentMisalignment (shutdown resistance, sandbagging, power-seeking) and CH7TfRLqSF Bayesian-IRL alignment auditor.
- AI-text detection now faces agentic evasion. In 8dYaiUpvvT, Claude Opus 5 running in Claude Code stitches samples from a local OLMo-2 base model, cutting Pangram v4 detection from 77% to 24% and also defeating watermarks. Defences continue: EFOrHqyVJz uses an LLM judge's token probability as a zero-shot detector, and A0WraHrgoe / EAXPtaoUft / cTekVoqmpm watermark text and code. pOxoEpizbq watermarks the affective tone of responses so the mark survives paraphrasing before distillation.
- Privacy is moving toward agent context and identities. EsS6ecnNnV probes for contextual integrity and masks attention to restricted spans. SmtbT4zjoO PAUSE tests fact-level vs subject-level PII unlearning. 3xUklblyVO RouteMask and pHdeURRX0J MIRRA unlearn identities in VLMs/MLLMs, and UmLECpFH6C tackles face-recognition unlearning, where a forgotten identity and an unseen one look the same. im6cgUcEk8 CALLIOPE applies differential privacy to analytics over AI-usage conversations. 2026 privacy here is mostly classical DP theory and federated learning (SmQJJSD180, vOLx8BWwwJ).
- Topics steady in both years: MLLM object hallucination fixes at decoding or attention time (POPE/CHAIR style; v4oHNlaW1K, j6zb01oGZa, 2tlNBXplsI vs 8lHWG9Isnc), concept-erasure attacks (2026 AdbO333D0e, 2027 d7AZGUMdgp merging), deepfake / AIGC detection, and LLM unlearning. Generative-video safety is new in 2027: 8yFE4lxHYU VVA-Bench reports visual-prompt attacks on image-to-video models reaching 100% ASR on Wan 2.7 and 74.8% on Veo 3.1. Driving VLAs are new too: 29R8XbELEK ReasonBreak attacks NVIDIA Alpamayo. Model names in 2027 abstracts: GPT-5 / GPT-5.6, Claude Opus 4.7 / 5 / 5.5, DeepSeek-V4, Gemma-4, Qwen3. Recurring benchmarks: AgentDojo, AppWorld, AgentHarm, TOFU, RAGTruth/LLM-AggreFact, HealthBench, MLLMU-Bench.
