# ICLR 2027 vs 2026：RLVR / GRPO 类论文的 base model 变化

## 一句话结论

**Qwen 从"主流"变成了"几乎唯一的默认选项"，而且整体换代到了 Qwen3 / Qwen3.5。** 在摘要里点名了开源 base model 的 RLVR/GRPO 论文中，用 Qwen 的比例从 2026 年的 80% 涨到 2027 年的 92%，只用 Qwen 一个家族的论文从 55% 涨到 73%。**跌得最多的是 Llama（25% → 9%）和 DeepSeek-R1-Distill 系列（10% → 3%）。** 涨幅较小但统计上能看出来的是 OLMo（1% → 4%，主要是 OLMo-3）。Gemma、gpt-oss、SmolLM、MiMo 有小幅上涨，但样本太少，只能算"有苗头"。

## 数据与口径

- **数据范围**：ICLR 2026 投稿 19,813 篇，ICLR 2027 投稿 43,013 篇（2027 年还在评审中）。只看**标题、关键词和摘要**，数据集里没有全文。
- **怎么筛出 RLVR/GRPO 论文**：文本里出现 RLVR、GRPO、DAPO、GSPO、verifiable reward(s)、R1-Zero/R1-style、zero-RL 等明确术语，**同时**有 LLM/VLM/reasoning model 的上下文。按这个口径，2026 年有 713 篇，2027 年有 1,451 篇，占投稿的比例都在 3.6%–3.4% 左右，基本持平。
- **怎么识别模型家族**：用正则匹配各家族的模型名，例如 `Qwen3-4B-Base`、`Llama-3.1-8B-Instruct`、`DeepSeek-R1-Distill-Qwen-1.5B`。处理规则：
  - R1-Distill-Qwen 单独算作 R1-Distill，不重复计入 Qwen。
  - Qwen-Image 是文生图模型，已经排除。
- **分母**：在摘要里点名了至少一个"可作 base 的开源家族"的论文。2026 年有 165 篇，2027 年有 588 篇。分母里不算 DeepSeek-R1/V3/V4 和闭源模型，因为这些在摘要里大多是被当作引子、teacher、对手或 judge 提到的，不是被训练的 base。
- **为什么不用"占全部 RLVR 论文的比例"**：2027 年的摘要更爱写具体模型名。点名开源模型的比例从 28% 涨到了 41%。如果用全部 RLVR 论文做分母，所有家族都会"虚涨"。

## Qwen 内部：明显换代

| Qwen 代际 / 变体 | 2026 | 2027 |
|---|---:|---:|
| Qwen2 | 3.6% | 0.2% |
| **Qwen2.5** | **43.6%** | 24.7% |
| **Qwen3** | 26.1% | **52.9%** |
| **Qwen3.5 / 3.6 / 3.8** | 0% | **15.5%** |
| Qwen2.5-Math（原 RLVR"标配"） | 9.1% | 3.4% |
| Qwen-VL / Omni（多模态 RL） | 12.1% | 14.5% |
| Qwen MoE（如 30B-A3B、35B-A3B） | 1.8% | 4.1% |

把每篇用 Qwen 的论文按"它提到的最新一代"归类，结果如下：

| 年份 | 最新一代的分布 |
|---|---|
| 2026 | Qwen2.5 占 48%，Qwen3 占 33% |

## 模型规模：往小模型移

下表的分母是点名了开源模型的论文。一篇论文可能提到多个尺寸。

| 参数规模 | 2026 | 2027 |
|---|---:|---:|
| ≤2B | 15% | 25% |
| 3–4B | 21% | **37%** |
| 7–9B | 44% | 52% |
| 12–14B | 7% | 5% |
| 27–35B | 12% | 13% |
| ≥70B | 8% | **2%** |

Qwen3-1.7B、Qwen3-4B、Qwen3.5-4B 这类小模型成了做 RLVR 方法实验的主力。≥70B 的大模型（包括 Llama-70B 和 Qwen2.5-72B）几乎消失了。

## 怎么解读

1. **Qwen 一家独大的程度在加深。** 2026 年已经有论文（如 *Spurious Rewards*）警告"在 Qwen2.5-Math 上用随机奖励也能涨分，RLVR 结论应该换个模型家族验证"。但 2027 年反而更集中在 Qwen：只用 Qwen 的论文从约 55% 涨到约 73%。
   - 这不是 RLVR 独有的现象。在所有其他 2027 投稿中，Qwen 的占比也从 47% 涨到了 70%，Llama 从 44% 跌到 22%。
   - 但 RLVR 子领域的集中度一直比全局更高，2027 年 92% 对全局 70%。
2. **Llama 退出 RLVR 主流。** 2027 年还在用的主要是 Llama-3.1-8B 和 Llama-3.2-1B/3B。它们多被当作"第二个家族"做泛化验证，或者用在安全、jailbreak 实验里当 victim。2027 年的 RLVR 摘要里没有看到 Llama-4。
3. **"从 R1-Distill 出发"的路线降温。** DeepSeek-R1-Distill-Qwen-1.5B、DeepScaleR 这类 2025 年流行的长 CoT 起点，被 Qwen3 自带 thinking 的模型（如 Qwen3-4B/8B）替代了。
4. **DeepSeek 本体的"下跌"大多不是 base model 的变化。** 2026 年有 26% 点名模型的 RLVR 摘要提到 DeepSeek，但抽读发现，绝大多数是"Inspired by DeepSeek-R1……""GRPO, introduced by DeepSeek……"这类引子。到 2027 年，RLVR 已经不需要用 R1 来铺垫了，所以这个比例掉到 3–4%。真正拿 DeepSeekMath-7B 或 DeepSeek-V4-Flash 做 base 训练的论文两年都很少。
5. **小幅上涨的家族都和"开放程度"有关。**
   - **OLMo-3** 公开了 RL-Zero 和中间 RLVR checkpoint，因此被用于训练过程分析，比如 checkpoint 演化、probe 迁移、instrumental convergence。
   - **Gemma-4**、**gpt-oss-20b/120b**、**SmolLM2/3**、**Nemotron-3-Nano**、**MiMo** 开始作为"非 Qwen 对照组"出现，但每个都只有个位数到二十篇左右。

## 稳健性检查

结论在以下口径下方向一致，数值见 `work/tables.md`：

| 检查口径 | Qwen | Llama | R1-Distill | OLMo |
|---|---|---|---|---|
| 去掉 withdrawn / desk_rejected | 81% → 93% | 24% → 9% | 11% → 3% | 1% → 4% |
| 去掉 2027 年"格式化文风"摘要（只剩 771 篇） | 68% → 90% | 20% → 10% | — | 0.5% → 5% |
| 换成更宽的"任意 RL + LLM"口径（3,373 篇 vs 1,702 篇） | 67% → 87% | 21% → 9% | — | — |

注：第 1 行用主表分母；第 2、3 行用的是含 DeepSeek-R1 引用论文的宽分母（见 work/tables.md），所以 2026 基线更低。

在"去掉 R1/V3 引用"这一口径下，Qwen 的升幅最小，为 +12pp。如果分母包括只提到 DeepSeek-R1 的论文，Qwen 的升幅是 +24pp。

## 局限

- **只有摘要。** 2026 年只有约 28% 的 RLVR 摘要点名开源模型，2027 年约 41%。没写模型名的论文无法判断，而且全文里常常还有附录模型。
- **"提到"不等于"作为 base 训练"。** 抽读了约 70 篇的上下文：
  - Qwen 和 Llama 的提及绝大多数确实是被 RL 训练的 policy。
  - 少数是 judge、victim、teacher 或纯分析对象。
  - DeepSeek 本体主要是引用。
  - 闭源模型（GPT、Claude、Gemini）基本都是对比对象或 judge，没有放进主表。
- **2027 年的 tldr 字段已排除。** 2027 年有 56% 的论文带 tldr，2026 年这个字段是空的。为了可比，本分析没有使用 tldr。
- **2027 年还没有评审结果。** 这里反映的是投稿时的选择，不是被接收论文的选择。
- 部分模型版本号（如 Qwen3.5/3.6/3.8、Gemma-4、GLM-5.x、DeepSeek-V4）按数据原样统计，没有做外部核实。
